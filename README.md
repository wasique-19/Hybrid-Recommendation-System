# Dataset

This folder contains the datasets used for the Hybrid Recommendation System project.

## Planned Dataset

The primary dataset for this project is the **MovieLens 100K dataset**.

The dataset will be used for:

* User information
* Movie information
* Movie genres
* User ratings
* Collaborative filtering
* Content-based filtering
* Hybrid recommendation
* Deep learning and embedding-based models

## Dataset Structure

The MovieLens dataset will be added inside:

```text
dataset/
└── ml-100k/
```

## Note

The dataset files will be added and explored during **Day 2** of the project.

Processed datasets and generated features will be stored separately in the `processed_data/` folder.
